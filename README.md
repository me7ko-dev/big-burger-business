# Big Burger Business 🍔

Игра за готвене и управление на ресторант: печеш кюфтета, пържиш картофки, режеш домати, наливаш кола/фанта/спрайт,
сервираш на клиентите, печелиш пари, купуваш подобрения и наемаш персонал.

**Играй тук (телефон и компютър):** https://me7ko-dev.github.io/big-burger-business/

- На телефона: отвори линка → менюто на браузъра → „Добави към началния екран“ → играе се като приложение, дори без интернет.
- Обърни телефона хоризонтално.

## Как се пуска

| Какво | Команда |
|---|---|
| Windows програма | иконата „Big Burger Business“ на работния плот (`release/BigBurger-win32-x64/BigBurger.exe`) |
| Нова Windows програма след промени | `npm run exe` |
| За разработка в браузъра | `npm run dev` → http://localhost:5173 |
| Сглобяване за уеб | `npm run build` (папка `dist`) |

Публикуването в GitHub Pages става автоматично при всяко качване в `main`.

## Технологии

Phaser 3 + TypeScript + Vite. Цялата графика е векторна (SVG в `src/art/svg.ts`), звуците и музиката се
генерират с Web Audio (`src/audio/sfx.ts`). Балансът (цени, времена, подобрения, нива) е в `src/config/game.ts`.
