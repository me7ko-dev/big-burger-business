# Big Burger Business — бележки

Игра за готвене (като Cooking Fever). Само за лична употреба. Потребителят не пише код и не чете английски — всичко на български.

## Пускане
- Windows: иконата на работния плот → `release/BigBurger-win32-x64/BigBurger.exe` (Electron 44, `npm run exe`).
  Самият electron.exe само се преименува (не се пипа) — заради Windows Smart App Control. Електрон бинарникът
  се сваля с `node node_modules/electron/install.js` (npm блокира postinstall скриптовете).
- Браузър/телефон: https://me7ko-dev.github.io/big-burger-business/ (GitHub Actions → Pages при push в main).
- Разработка: `npm run dev`; тестове искат `npx vite preview --port 4173` да върви.

## Тестове (Playwright от глобалния npm: `export PW="$(npm root -g)/playwright"`)
- `node test/play1.mjs` — изиграва обучението на ниво 1 с кликове.
- `node test/bot.mjs 1 20 8 0.7` — робот през вътрешното API; `ONE=1` = едно действие на ход (като човек);
  `UP='{"tables":3}'` = с подобрения; `SHOTS=1` = снимки. Показва пари/звезди/изгубени за всяко ниво.
- `node test/shot.mjs Map|Shop|Tasks|Game [ниво]`, с `SAVE='{...}'` за готов прогрес. `node test/mobile.mjs` — Pixel 7 с докосване.
- `node test/icons.mjs` — прави иконите от бургера в играта.

## Структура
- `src/scenes/GameScene.ts` — залата, масите, клиентите, HUD, вход (докосване/влачене/задържане/плъзгане), персонал, обучения, край на деня.
- `src/game/stations.ts` — скара (обръщане, изгаряне), фритюрник (зони на лентата), витрина + солница, автомат (задържане до чертичката, преливане),
  сглобяване на бургери (чинии), дъска за домати, кофа.
- `src/game/customer.ts` — клиент: влиза/опашка/сяда/поръчва/търпение/яде/плаща/сърдит си тръгва.
- `src/config/game.ts` — всички числа, подобрения, типове клиенти, локации, генератор на нивата и целите.
- `src/data/save.ts` — запис в localStorage (`bbb-save-v1`).
- Други сцени: Menu (дневна награда, офлайн печалба от мениджъра), Map (20 нива), Shop (кухня/зала/персонал/бустери), Tasks (задачи + постижения), Result, Pause.
